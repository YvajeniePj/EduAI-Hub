# EduAI Hub - Микросервисная образовательная платформа

Современная экосистема для управления образовательным процессом, построенная на базе микросервисной архитектуры. Платформа объединяет в себе инструменты для проведения тестов, онлайн-обучения, аналитики и AI-поддержки.

## 🛠 Технический стек

### Backend
- **Языки и фреймворки**: Python 3.10+, FastAPI
- **Базы данных**: PostgreSQL (основное хранилище), Redis (кэширование и очереди)
- **Стриминг**: LiveKit (WebRTC-платформа для видеосвязи)
- **AI Интеграция**: GigaChat API (от Сбера)
- **ORM**: SQLAlchemy

### Frontend
- **Фреймворк**: Angular 17+ (Standalone компоненты)
- **UI/UX**: Material Design, CSS3 (Vanilla + Grid/Flexbox)
- **State Management**: RxJS, Signals
- **Стриминг**: LiveKit JS SDK

### Инфраструктура
- **Контейнеризация**: Docker, Docker Compose
- **Reverse Proxy**: Nginx
- **Безопасность**: Certbot (SSL)

## 🏗 Архитектура

Проект реализован в виде 13 независимых микросервисов, взаимодействующих через API Gateway:

1.  **API Gateway**: Единая точка входа. Маршрутизация запросов, агрегация ответов.
2.  **Subject Service**: Управление учебными предметами, курсами и структурой обучения.
3.  **Test Service**: Конструктор тестов. Поддержка различных типов вопросов и вариантов ответов.
4.  **Submission Service**: Обработка результатов тестирования. Автоматическая проверка и начисление баллов.
5.  **Analytics Service**: Сбор и визуализация данных об успеваемости студентов и их активности.
6.  **AI Service**: Интеллектуальный помощник. Генерация тестов, помощь в обучении и автопроверка ответов.
7.  **Streaming Service**: Обеспечение живых трансляций, вебинаров и записи занятий.
8.  **Notification Service**: Система многоканальных уведомлений (внутренние, push).
9.  **Feedback Service**: Управление оценками, отзывами и обратной связью от студентов.
10. **Material Service**: Централизованное хранилище учебных материалов и документов.
11. **Video Service**: Обработка и стриминг видео-уроков (YouTube, VK, локальные файлы).
12. **Peer Review Service**: Модуль для взаимной проверки работ студентами ("рецензирование").
13. **Gamification Service**: Система вовлечения: очки опыта, достижения, уровни и глобальные лидерборды.

## 🌟 Основные функциональные возможности

- **Интерактивное обучение**: Прохождение тестов с мгновенными результатами.
- **Живое общение**: Трансляции в реальном времени с минимальной задержкой и встроенным чатом.
- **AI-поддержка**: Использование нейросетей для персонализации обучения и помощи преподавателям.
- **Аналитика в реальном времени**: Мониторинг прогресса каждой группы и студента.
- **Совместная работа**: Система peer-to-peer проверки заданий для развития критического мышления.
- **Геймификация**: Мощная система мотивации через игровые механики.
- **Мультимедиа**: Поддержка видео, аудио и текстовых материалов в рамках одного курса.

## 🔐 Безопасность и масштабируемость

- **Изоляция**: Каждый микросервис работает в собственном контейнере.
- **Масштабируемость**: Возможность горизонтального масштабирования отдельных высоконагруженных узлов (например, Test или Streaming).
- **Отказоустойчивость**: Сбои в одном сервисе (например, Gamification) не блокируют работу основного функционала.
- **HTTPS**: Встроенная поддержка автоматического получения SSL-сертификатов.
